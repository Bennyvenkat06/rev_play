## 4. Correct Challenge provenance

Every challenge must carry a transparent provenance status:

- `VERIFIED_PYQ`
- `PYQ_VARIANT`
- `SOURCE_MATCH_PENDING_PRIMARY_PDF`
- `SUPPLEMENTAL_CHALLENGE`

Use the available source evidence. Do not promote a question to `VERIFIED_PYQ` merely because it is related to a JNTUH syllabus topic.

Important findings to preserve:

- Floyd's Triangle: verified match in JNTUH R22, paper code 181AP, July/August 2024, question 2(b).
- Array monotonicity, whitespace compression, and vowel/consonant/digit counting: matching secondary-source transcripts exist for JNTUH R16, paper code 132AD, but primary-source verification is still pending.
- String palindrome: a matching question exists in JNTUH R16, paper code 132AD, January/February 2024. The additional `without string.h` restriction is a platform adaptation, not part of the original wording.
- The 181AP bit-shift question is not the same as an exercise requiring an 8-bit binary representation.
- Do not invent source details for saddle point, digital root, recursive GCD, or matrix trace.

Where source evidence is incomplete, preserve the question but label its provenance honestly.
